Entry for the make.fun bounty "Fortune in a Pot": one line, at most 120
characters — a fortune written for a houseplant. A judge model playing a
gardener of thirty years compares entries pairwise.

Run `python3 main.py` — it writes the line to `/output/entry.txt`.
